# Knowledge base sources and licences

`qa_dataset.json.gz` is generated by `tools/build_qa_dataset.py` from public Hugging Face datasets. Only datasets with a declared licence that permits redistribution are included. Licences below are as shown on each dataset's Hugging Face page on 2026-11-05; re-check them before relying on this list.

Rebuild (run both steps, in order):

1. `uv run --no-project --python 3.12 --with datasets python tools/build_qa_dataset.py`
2. `cd backend && uv run python scripts/prune_knowledge_gaps.py` removes entries covering the Knowledge Gap topics in `data/evaluation/knowledge_gaps.json` (92 entries removed from the 46,619 built from the licensed sources, leaving 46,527).

## Known content issues (tracked in PRODUCT_BACKLOG.md, item T05b)

- The 644 `strova-ai` HR entries are written for another company ("Kreeda Labs") and include its contact addresses (for example `hr@kreedalabs.com`). They must be rewritten for BuzzTech Solutions before they can be used as BuzzTech policy.
- Other email addresses in the data are placeholder domains (`acme.co`, `example.com`, `company.com`). A scan found no credentials or API keys.
- Entries are IT ticket resolutions rather than formal policy documents, so answers may read like support notes.
