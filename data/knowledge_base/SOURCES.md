# Knowledge base sources and licences

`qa_dataset.json.gz` is generated by `tools/build_qa_dataset.py` from public Hugging Face datasets, then cleaned by two scripts. Only datasets with a declared licence that permits redistribution, and with real answer text, are included. Licences below are as shown on each dataset's Hugging Face page on 2026-11-05; re-check them before relying on this list.

Synthetic BuzzTech content (Onboarding, Payroll & Compensation, HR Policy) lives separately in `synthetic/` and is described in its own README.

Rebuild (run all three steps, in order):

1. `uv run --no-project --python 3.12 --with datasets python tools/build_qa_dataset.py` builds 21,065 entries from the included sources. Rows without answer text are skipped.
2. `cd backend && uv run python scripts/prune_knowledge_gaps.py` removes 7 entries covering the Knowledge Gap topics in `data/evaluation/knowledge_gaps.json`.
3. `cd backend && uv run python scripts/normalize_company_content.py` cleans the borrowed HR entries (see below): 179 dropped, 115 rewritten.

The result is 20,879 entries (plus 56 synthetic entries, 20,935 in total).

The first version of the builder gave label-only rows an invented answer of the form `Ticket category: Security.`. Those entries (25,469, or 55% of the knowledge base at the time) were not knowledge: retrieval could have returned them as answers and they would have doubled indexing cost. The builder now skips rows without answer text, and a test fails if any such entry returns.

## Cleaning the borrowed HR entries

The `strova-ai` HR entries describe the policies of another company, "Kreeda Labs". `scripts/normalize_company_content.py` makes them safe to use for the fictional BuzzTech Solutions:

- **Dropped (23 entries)** that name real individuals (the original company's founder and HR staff) or are document sign-off boilerplate.
- **Dropped (156 entries)** on topics the synthetic BuzzTech handbook already covers (harassment complaints, remote work, leave, compensatory off, overtime, working hours). The borrowed answers differ from the handbook and also contradicted each other (for example 30 versus 60 days for compensatory off), so keeping them would let the agent give conflicting answers.
- **Rewritten (115 entries):** the company name becomes "BuzzTech Solutions", and `@kreedalabs.com` addresses become `@buzztech.example` (a reserved domain that cannot be a real address).

The 465 remaining entries cover anti-bribery, whistleblowing, confidentiality and similar compliance topics.

## Known content issues

- Some remaining borrowed entries may still contain small contradictions with each other (for example how many days a whistleblower report is acknowledged within). They are not covered by the synthetic handbook, so T08's retrieval evaluation should check whether they cause wrong answers.
- The IT entries (`KameronB`) are ticket resolution notes written in the third person ("The ticket was resolved by..."), so answers may read like support notes rather than customer-facing articles.
- A scan found no credentials or API keys.
